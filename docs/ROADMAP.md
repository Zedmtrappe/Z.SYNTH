# ZYNTH roadmap

Ideas and requests that are agreed but not built yet. Newest first.

## Presets

* **"Add to favourites" and a Favourites folder.** Already in the app: the
  preset browser has a star per preset, a FAVOURITE button and a "Favourites
  only" filter, and favourites persist across sessions. To do:
  * an explicit "Add to favourites" / "Remove from favourites" item in the
    header's preset menu (and on right-click of a preset in the browser);
  * a **Favourites** folder at the top of the header's Bank > Folder > Preset
    menu and in the browser's folder list, so favourites can be stepped
    through with the < > buttons like any other folder.
* **"Set as startup sound"** from the preset menu, instead of building a
  preset into the factory bank.

## Sound

* **Sample playback oscillator**: load WAV / SFZ multisamples from a folder on
  disk (e.g. legally owned libraries sampled from 90s workstations), keymapped
  with loop points, through the existing filters, envelopes and effects.

## Effects and routing

* **External side-chain input** for the output compressor (VST3 / AU aux bus).
